# ZZLM 跳转入口

入口：https://hwxc129.github.io/simple-post/

目标：https://zzlm.my/

打开入口后浏览器自动跳转到目标网站，保留手动打开链接。
JavaScript 使用 `location.replace`，并提供无需 JavaScript 的 HTML 刷新跳转。
不会把入口的查询参数或片段附加到目标地址，不加载外部脚本、图片或字体。

这是 GitHub Pages 上的跳转页，浏览器最终访问 `zzlm.my`，不代理原站请求。

修改 `index.html` 后提交到 `main` 分支，GitHub Pages 会自动更新。
